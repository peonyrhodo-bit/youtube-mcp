# Журнал решений

## 2026-11-19
1. Техническое руководство и приоритизация — на стороне ассистента; владелец решает только вопросы, которые нельзя безопасно решить без неё.
2. Codex — исполнитель конкретных ограниченных заданий, не самостоятельный определитель продукта. Пока передача задания в Codex из этого чата не автоматизирована.
3. `тз` и `тз директор 3,0` неизменяемы, включая название и расположение.
4. Все изменения сначала изолируются в ветках; не менять production-код без подтверждённого дефекта и приёмки.
5. Не создавать платных зависимостей, учитывать малую память Render.
6. Пропуски запуска из-за засыпания Render пока не исправлять.
7. Старые документы не удалять автоматически; владелец может хранить локальные копии.
8. Владелец запросил удаление лишнего Render-сервиса. По текущей инвентаризации единственный дополнительный — `site-insight-engine-pr21-isolated`; удаление пока не совершено.
9. Ведение управляющих документов в GitHub разрешено владельцем. Первоначально создаём их в отдельной ветке, без автоматического деплоя.
