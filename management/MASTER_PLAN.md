# Единый рабочий план — ИИ-директор YouTube 3.0

> **Единственный действующий список работ.** Переработка существующего файла 22.11.2026. Дубли OOM, Memory 2.0, функционального восстановления, BACKLOG, P01–P26 и отдельных заданий Codex сведены к одной очереди. Оригиналы пока сохранены и **не являются рабочими списками**. Никаких изменений программного кода, Render, Supabase или ТЗ.

## Состояние проекта

- **Прогресс: 6/40 уникальных основных задач завершено и исторически проверено; 34 не завершено (15%).** Вложенные препятствия — части своих основных задач, отдельно в знаменатель не входят.
- **Текущий активный пункт: №07 — воспроизвести путь от уже сохранённых данных до рекомендации.** Это технический шаг к результату, а не очередной общий аудит и не автоматический старт с прежнего №009.
- **Блокировки:** неизвестно, где прерывается цепочка analytics → decision → persistence; чтение защищённой памяти (Issue #68), RAM Render 512 MiB (OOM-07), неподтверждённая связь сервисов; возможный Supabase 402; конфликт PR #73 с требуемой автономностью. Непроверенные блокировки отмечены условными.
- **Следующее действие:** на существующих offline-фикстурах и коде проверить последовательные вызовы `analytics → Director → recommendations`, зафиксировать первый воспроизводимый сбой; затем устранить его после отдельного разрешения на изменение кода. Параллельно новые YouTube-вызовы не нужны.
- **Цель:** YouTube-исследование → доказательная аналитика → рекомендация → сохранение → русский сайт → feedback → следующий цикл.

## Правила исполнения

**[x]** — выполнено и проверено; **[ ]** — не завершено. Слова **ЧАСТИЧНО / БЛОКИРОВАНО / УСЛОВНО / ОТЛОЖЕНО** уточняют незавершённый пункт. Один основной флажок = одна уникальная работа; вложенные флажки = её препятствия/этапы, не отдельные дубли. Закрывать основной пункт только по указанной приёмке с ссылкой на тест/коммит/лог и датой. При препятствии выполнить вложенную задачу и вернуться к родителю. Программный код, продакшен, платные запросы, миграции, удаление данных — лишь по отдельному разрешению.

**Границы:** не ломать существующую архитектуру; 3 репозитория, бесплатные Render/Supabase; quota manager считает квоту, Director принимает решение; защищённую историю и пользовательские согласия не удалять; автономность не подменять настройкой `AUTONOMOUS_ENABLED`; предупреждения RLS не трактовать как разрешение на опасные изменения. Исходные ТЗ и технические доказательства сохраняются. Наличие кода, CI или HTTP 200 само по себе не означает работающий результат.
